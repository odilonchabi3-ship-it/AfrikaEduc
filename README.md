# AfrikaEduc
AfrikaEdu 🌍 est une application web innovante et 100% autonome, conçue pour booster la réussite scolaire en Afrique. Du collège au bac, elle propose des cours interactifs adaptés aux réalités locales (Maths, Physique, Histoire). Grâce à ses quiz et un système captivant de points XP stockés sans connexion, réviser devient un jeu d'enfant !
